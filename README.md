# Credit Card Fraud Detection

This project detects credit card fraud using Random Forest and SMOTE.

## How to Run
1. Install packages: `pip install -r requirements.txt`
2. Run the script: `python src/train.py`

## Outputs
- Classification report in terminal
- Confusion matrix, ROC curve, and feature importance graphs

## Dataset
Place `creditcard.csv` in the `data/` folder
